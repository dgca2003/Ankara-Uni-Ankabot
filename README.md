# 🤖 Ankabot - RAG Tabanlı Öğrenci Asistanı

Ankabot, öğrencilerin üniversite yönetmeliklerine, ders materyallerine ve duyurulara anında ulaşabilmesi için geliştirilmiş bir yapay zeka asistanıdır. Bu proje, **ASP.NET Core** altyapısı ve **Yerel Büyük Dil Modelleri (LLM)** ile RAG (Retrieval-Augmented Generation) mimarisi kullanılarak geliştirilmektedir.

## 🚀 Projenin Amacı
Öğrencilerin bilgiye erişim süresini kısaltmak ve kurum içi iletişim verimliliğini artırmak. RAG mimarisi sayesinde model, halüsinasyon görmeden sadece üniversiteye ait resmi belgeler (PDF, Word, Web metinleri) üzerinden cevap üretir.

## 🛠️ Kullanılan Teknolojiler
* **Backend:** ASP.NET Core Web API, C#
* **Yapay Zeka (LLM):** Llama 3 / Mistral (Yerel olarak çalıştırılmaktadır)
* **Vektör Veritabanı:** Qdrant / ChromaDB / Pinecone (Hangisini seçecekseniz)
